Vendored on purpose. This bundle holds the GitHub OAuth token in the browser, so it is
pinned here instead of being pulled from a CDN on every page load.

To upgrade:

  V=<new-version>
  curl -sL "https://registry.npmjs.org/@sveltia/cms/-/cms-$V.tgz" | tar -xz -C /tmp
  cp /tmp/package/dist/sveltia-cms.js static/admin/sveltia-cms.js
  sha256sum static/admin/sveltia-cms.js     # then update this file

Read the release notes before upgrading. Check that the diff is what you expect.
